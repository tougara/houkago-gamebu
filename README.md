# 放課後ゲーム部

「スマホ1台でみんなで遊ぼう！」をテーマにした、スマホ向けブラウザゲーム集です。

## 現在遊べるゲーム

### ニセ転校生を探せ！
3〜10人向けの正体隠匿・推理ゲーム。

実装済み：
- 人数選択（3〜10人）
- 名前入力
- プレイヤーアイコン選択
- 使用役職選択（人数＋お休み2枚）
- ニセ転校生2枚固定
- 役職公開の誤操作防止（長押し＋伏せ画面）
- 夜行動
- プレイ中の役職確認／レギュ確認
- 話し合いタイマー
- 秘密投票
- 席替え後の最終役職による勝敗判定
- 「ホンモノサイド勝利！」「ニセモノサイド勝利！」「平和なクラス！」の結果表示

## 構成

- `/` 放課後ゲーム部トップ
- `/games/nise-transfer-student/` ニセ転校生を探せ！

静的HTML/CSS/JavaScriptのみで動作します。Cloudflare Pagesなどへそのまま配置できます。
